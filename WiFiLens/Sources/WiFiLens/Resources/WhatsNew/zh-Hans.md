# WiFi Lens 2.1.0 更新内容

## 分析体验调整

* Analysis 现在提供 Network Experience 和 Problem History，分别用于了解网络可靠性与历史基线，以及回顾已记录的问题和相关证据。
* Statistics 和 Insights 已退役。
* Timeline 仍可用于查看和导出已有的历史事件，但已不再生成新的 Timeline 记录或分析。

## 可选的后台观察

* 开启后，即使退出 WiFi Lens Pro，应用仍会记录 Wi-Fi 连接状态与网关响应。此功能默认关闭。
* Mac 睡眠时不会记录，唤醒后自动继续。数据保存在本机，不会上传。
* 关闭此开关即可停止后台观察。

## 开源许可证

你可以在应用中查看所使用的开源组件及其许可证信息。我们尊重各项开源许可证，并感谢开源社区及维护者的工作成果。

## WiFi Lens 2.0.1 更新内容

这次更新让 WiFi Lens 更清楚地呈现当前能够确认的信息。无法确认的连接状态和单项指标会显示为“未知”；过期读数不再作为当前值；扫描失败时会清空网络列表，避免旧读数被误认为当前结果。

漫游测试现在只在能够连续确认的采样之间记录切换。信号曲线会在没有测量的时间段留空，悬停时可以同时查看该时刻各个 AP 的读数。

界面方面，AP Radar 和 Network Check 去掉了与窗口标题重复的标题，工具栏标题徽章也改善了 VoiceOver 支持。

## WiFi Lens 2.0 回顾

WiFi Lens 2.0 改进了 Wi-Fi 信息识别与网络排查体验。

### 更完整的 Wi-Fi 信息

* 加强对附近接入点广播信息的解析。
* 更准确地识别当前信道宽度，包括 20、40、80、160 和 80+80 MHz。
* 改进对 WPA3、安全加密套件、802.11k/r/v/w、Wi-Fi 代际、MCS 和空间流等信息的识别。
* 遇到缺失、截断或格式异常的信息时，更明确地呈现无法确认的内容，避免用猜测补全结果。

### 更清晰的网络排查

* 改进 Network Self-Check，用于检查网络连通性、DNS、HTTPS、IPv6 和已配置的代理。
* 让频谱、信道、接口、AP Radar 和网络诊断页面中的 Wi-Fi 信息更一致。
* 提升 Pro 中已有历史记录的读取与迁移可靠性，帮助升级后继续查看已有记录。

### AI 与 MCP

启用 MCP Server 后，兼容的 AI 客户端可以通过本机连接读取实时 Wi-Fi 信息。
