# 2.0 更新内容

WiFi Lens 2.0 是一次重要的基础版本更新，重点提升 Wi-Fi 分析的准确性、可靠性与一致性。

## 加入社区

有问题、想反馈，或者只是想聊聊 WiFi Lens？

**加入 Discord：** https://discord.gg/gH6sTCYaJ7

## 更深入的 Wi-Fi 协议解析

* 加强对附近接入点广播的 802.11 Information Elements 底层信息解析。
* 更准确地识别当前实际信道宽度，包括 20、40、80、160 和 80+80 MHz。
* 改进 WPA3、安全加密套件、802.11k/r/v/w、Wi-Fi 代际、MCS 和空间流等能力识别。
* 对缺失、截断或格式异常的无线信息采用更保守的处理方式，不再通过猜测生成可能误导的结果。

## 更可靠的故障排查基础

* 重构 Network Self-Check，以更清晰、基于证据的方式检查网络连通性、DNS、HTTPS、IPv6 和已配置的代理。
* Wi-Fi 分析功能现在建立在更统一的内部架构上，提升频谱、信道、接口、AP Radar 和网络诊断之间的一致性。
* 重新设计运行环境与数据存储机制，进一步提升数据可靠性，并减少不同运行环境之间的相互影响。

## WiFi Lens Pro

* 提升 Timeline 存储与历史数据处理的可靠性，并为已有安装提供更安全的数据迁移机制。
* 加强长期观测的底层能力，为历史记录、Statistics、Insights 和后续调查工作流提供更可靠的基础。
* 正式版与开发版现在拥有隔离的应用身份、存储空间和 MCP 端点。

## AI 与 MCP

* 内置 MCP Server 与应用运行环境的集成更加稳定。
* 启用后，兼容的 AI 客户端仍然可以通过本机 MCP 端点访问实时 Wi-Fi 信息。
* 开发环境与正式环境之间的 MCP 服务现在拥有更严格的隔离。

## 稳定性

* 改进数据持久化边界、启动验证、日志、崩溃诊断和 MetricKit 数据存储。
* 针对网络诊断、本地化、辅助功能和运行时行为补充了大量修复与测试。

WiFi Lens 2.0 为理解无线环境实际广播的能力信息，以及后续排查偶发网络问题，建立了更可信的基础。
