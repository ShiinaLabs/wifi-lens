# 2.0 版最新動態

WiFi Lens 2.0 強化了產品基礎，讓 Wi-Fi 分析更準確、可靠且一致。

## 深入分析 Wi-Fi 通訊協定

* WiFi Lens 現在能更穩健地低階解析附近 AP 所廣播的 802.11 Information Elements。
* 改善實際運作信道寬度的偵測，包括 20、40、80、160 和 80+80 MHz 設定。
* 更可靠地辨識 WPA3 安全性、加密套件、802.11k/r/v/w 能力、Wi-Fi 世代、MCS 和空間串流。
* 對格式錯誤或不完整的無線中繼資料採取更審慎的處理方式，不再臆測能力資訊，減少造成誤解的結果。

## 更穩固的故障排除基礎

* 重新打造 Network Self-Check，以更清楚且根據證據的方式診斷連線能力、DNS、HTTPS、IPv6 和已設定的代理伺服器。
* Wi-Fi 分析元件現在採用更一致的內部架構，改善 Spectrum、Channels、Interfaces、AP Radar 和診斷功能之間的一致性。
* 重新設計執行環境與儲存處理方式，更妥善保護使用者資料，並提升不同 App 環境下的可靠性。

## WiFi Lens Pro

* Timeline 儲存和歷史資料處理更可靠，也為既有安裝提供更安全的資料移轉方式。
* 強化長期觀測基礎，為歷史資料、Statistics、Insights 和調查工作流程提供更可靠的支援。
* 正式版和開發版現在使用彼此隔離的 App 身分、儲存空間和 MCP 端點。

## AI 與 MCP

* 內建 MCP 伺服器與 App 執行環境的整合更加完善。
* 相容的 AI 用戶端仍可透過「設定」中啟用的 MCP 端點，在本機存取即時 Wi-Fi 資訊。
* 開發版和正式版之間的 MCP 環境隔離更加完善。

## 可靠性

* 改善資料持久化邊界、啟動驗證、記錄檔、當機診斷和 MetricKit 儲存。
* 為網路、診斷、本地化、輔助使用和執行環境行為加入多項修正與測試。

WiFi Lens 2.0 提供更可信賴的基礎，協助你理解無線環境實際廣播的資訊，並在問題發生時進行調查。
