# WiFi Lens 2.1.0 更新內容

## 分析體驗調整

* Analysis 現在提供 Network Experience 和 Problem History，分別用於了解網路可靠性與歷史基準，以及回顧已記錄的問題和相關證據。
* Statistics 和 Insights 已退役。
* Timeline 仍可用來檢視和匯出既有的歷史事件，但已不再產生新的 Timeline 記錄或分析。

## 可選的背景觀測

* 開啟後，即使退出 WiFi Lens Pro，App 仍會在背景持續觀察網路狀況。此功能預設為關閉。
* Mac 睡眠期間不會記錄，喚醒後會自動繼續。資料保存在本機，不會上傳。
* 關閉此開關即可停止背景觀測。

## 開源授權

你可以在 App 中檢視所使用的開源元件及其授權資訊。我們尊重各項開源授權，並感謝開源社群及維護者的成果。

## WiFi Lens 2.0.1 更新內容

這次更新讓 WiFi Lens 更清楚地呈現目前能夠確認的資訊。無法確認的連線狀態和個別指標會顯示為「未知」；過期讀數不再作為目前值；掃描失敗時會清空網路列表，避免舊讀數被誤認為目前結果。

漫遊測試現在只會在能夠連續確認的取樣之間記錄切換。訊號曲線會在沒有測量的時段中斷，懸停時可以同時查看該時刻所有 AP 的讀數。

介面方面，AP 雷達和網路檢查移除了與視窗標題重複的標題，工具列標題徽章也改善了 VoiceOver 支援。

## WiFi Lens 2.0 回顧

WiFi Lens 2.0 改善了 Wi-Fi 資訊辨識與網路疑難排解體驗。

### 更完整的 Wi-Fi 資訊

* 加強對附近存取點所廣播資訊的解析。
* 更準確地辨識目前信道寬度，包括 20、40、80、160 和 80+80 MHz。
* 改善對 WPA3、加密套件、802.11k/r/v/w、Wi-Fi 世代、MCS 和空間串流等資訊的辨識。
* 遇到缺漏、截斷或格式異常的無線資訊時，更清楚地呈現不確定性，不再以猜測補齊。

### 更清楚的網路疑難排解

* 改善 Network Self-Check，用於檢查網路連線、DNS、HTTPS、IPv6 和已設定的代理伺服器。
* 讓 Spectrum、Channels、Interfaces、AP 雷達和網路診斷頁面中的 Wi-Fi 資訊更加一致。
* 改善 WiFi Lens Pro 讀取及移轉既有歷史資料的可靠性，讓你升級後仍可檢視原有記錄。

### AI 與 MCP

啟用 MCP Server 後，相容的 AI 用戶端可以透過本機連線存取即時 Wi-Fi 資訊。
