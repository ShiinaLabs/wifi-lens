# WiFi Lens 2.1.0 の新機能

## 分析機能を刷新

* 分析に「ネットワーク体験」と「問題履歴」が加わりました。ネットワークの信頼性や過去の基準値を確認したり、記録された問題とその根拠を振り返ったりできます。
* Statistics と Insights は提供を終了しました。
* Timeline では、既存の履歴イベントを引き続き表示・書き出しできます。Timeline は非推奨となり、新しい記録や分析は追加されません。

## 任意のバックグラウンド観測

* 有効にすると、WiFi Lens Pro を終了した後も、Wi-Fiの接続状態とゲートウェイの応答を記録します。この機能は初期状態でオフです。
* Macがスリープ中は記録せず、復帰後に自動的に再開します。データはMac内に保存され、外部へ送信されません。
* この設定をオフにすると、バックグラウンド観測を停止できます。

## オープンソースライセンス

アプリで使用しているオープンソースのコンポーネントとライセンスを確認できます。私たちは各ライセンスを尊重し、オープンソースコミュニティとメンテナーの成果に感謝しています。

## WiFi Lens 2.0.1 のアップデート

確認できる情報をより分かりやすく表示するようになりました。確認できない接続状態や個別の指標は「不明」と表示され、古い測定値は現在の値として表示されなくなりました。スキャンに失敗するとネットワーク一覧が消去され、古い測定値が現在の結果と誤認されるのを防ぎます。

ローミングテストでは、連続して確認できるサンプル間でのみ切り替えを記録します。測定がない時間帯では信号曲線が途切れ、その時点のすべてのAPの測定値をホバーで確認できます。

APレーダーとネットワーク診断では、ウィンドウタイトルと重複する見出しを削除しました。また、ツールバーのタイトルバッジのVoiceOver対応を改善しました。

## WiFi Lens 2.0 の振り返り

WiFi Lens 2.0では、Wi-Fi情報の識別とネットワーク診断の使いやすさを改善しました。

### より充実したWi-Fi情報

* 近くのアクセスポイントが通知する情報の解析を改善しました。
* 使用中のチャネル幅をより正確に識別します。20、40、80、160、80+80 MHzの構成に対応します。
* WPA3、暗号スイート、802.11k/r/v/wの機能、Wi-Fi世代、MCS、空間ストリームの識別を改善しました。
* 無線情報が欠落、切り詰め、または不正な形式の場合、推測で補わず、不確かな情報であることを分かりやすく示します。

### 分かりやすいネットワーク診断

* Network Self-Checkを改善し、接続、DNS、HTTPS、IPv6、設定済みプロキシを確認できます。
* Spectrum、Channels、Interfaces、APレーダー、ネットワーク診断で表示するWi-Fi情報の一貫性を高めました。
* WiFi Lens Proで既存の履歴をより確実に読み込み、移行できるようになり、アップデート後も履歴を確認できます。

### AIとMCP

MCP Serverを有効にすると、互換性のあるAIクライアントがローカル接続を通じてリアルタイムのWi-Fi情報にアクセスできます。
